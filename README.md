# Wind Energy & Atmospheric Phenomena Ontology

A domain ontology developed for the **Ontology Engineering** course at the Federal University of Santa Maria (**UFSM**) during the second semester of 2026. 

This repository provides the primary `.owl` file modeling the relationships between wind turbine operational mechanics and key atmospheric/meteorological phenomena.

## Repository Contents
* `WindTurbineOntology.owx` - The main Web Ontology Language (OWL) file containing the classes, object/data properties, and axioms.
